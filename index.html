    How to use StoryMap Planner

    1. Add sections using + Add section or load a template.
    2. Select a section card and fill the right panel details.
    3. Drag cards to reorder, or use move up/down buttons and keyboard.
    4. Use Export for JSON, Markdown, plain text, or printable storyboard.

    Keyboard controls

    • Tab / Shift+Tab: move between controls
    • Enter: open buttons and actions
    • Alt + Arrow Up/Down on selected card: move section
    • Delete on selected card: delete section
